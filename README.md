# Windows Pad

Launcher Android inspirado na experiência de desktop do Windows 11, desenvolvido para o Redmi Pad Pro.

## Objetivo
- Interface adaptável aos temas claro e escuro do Android.
- Tela inicial com aplicativos instalados.
- Barra de tarefas e pesquisa.

## Desenvolvimento
Projeto Android nativo. Configuração e instruções de compilação serão adicionadas junto com os arquivos do aplicativo.
